# 변경 기록

이 프로젝트의 주요 변경 사항을 기록합니다.

- 앱 인터페이스, 자동 및 수동 언어 선택, README, 앱 내 버전 기록에 독일어, 아랍어, 힌디어 지원을 추가했습니다.
### 수정됨
- DNS 편집기에서 MX 및 SRV 레코드의 생성과 수정에 필요한 추가 필드를 처리하도록 수정했습니다.

## [2.1.0] - 2026-10-19
### 추가됨
- DNS 레코드의 주소 또는 값 복사, 복제, 편집, 삭제를 위한 작업 메뉴를 추가했습니다. 마우스 오른쪽 버튼으로도 시스템 언어로 같은 작업을 사용할 수 있습니다.
- 접근 가능한 Cloudflare 계정에 새 도메인을 추가하는 기능을 추가했습니다.
- 활성화 대기 중인 도메인에 할당된 네임서버를 표시하고 복사 및 활성화 재확인을 지원합니다.
- 토큰에 `Memberships → Read` 권한이 없으면 도메인이 하나 이상 있는 계정만 표시된다는 안내를 추가했습니다.
- 도메인 추가 시 계정 선택 화면에서 이름 또는 ID 검색과 `Ctrl+F`, `Esc` 단축키를 지원합니다.
- 토큰에 영역 생성 권한이 있을 때만 도메인 추가 옵션을 표시합니다.
- 앱 사용에 필요한 권한 설명을 개선했습니다.
### 수정됨
- 토큰 안내를 정리했습니다. 기존 영역의 기본 권한은 Zone Edit와 Cache Purge이며, 도메인 추가 및 DNS 관리 권한에는 DNS Edit가 포함됩니다.
- 앱 아이콘과 메타데이터를 포함한 iOS/App Store 게시 설정을 수정했습니다.
- 다른 경고의 `-Werror` 설정은 유지하면서 Linux 빌드의 C++ 종속성 `deprecated-literal-operator` 경고 수준을 낮췄습니다.
- 기존 비밀번호 해시와의 호환성을 유지하면서 네이티브 플랫폼의 비밀번호 생성 및 확인 계산을 isolate로 옮겼습니다.
- 비밀번호 설정, 로그인, 변경, 재인증에서 동시 제출을 막고 실패 시 다시 시도할 수 있게 했습니다.

## [1.1.2] - 2026-06-26
### 추가 / 수정됨
- DNS 레코드 생성 및 편집 시 입력 내용 검사를 추가했습니다.
- `A` 레코드에 IPv4, `AAAA` 레코드에 IPv6 검사를 추가했습니다.
- 고정된 최상위 도메인 목록 없이 `CNAME`, `MX`, `NS`의 도메인 형식을 검사합니다.
- `SRV`의 기본 형식과 `TXT` 내용이 비어 있지 않은지 검사합니다.
- `CNAME`, `MX`, `NS`, `SRV` 대상에 IP 주소를 입력할 수 없도록 수정했습니다.
- 프록시를 사용할 수 없는 DMARC, DKIM 등의 `TXT` 레코드 생성 시 `proxied` 필드를 보내지 않도록 수정했습니다.
- `Proxied` 설정은 `A`, `AAAA`, `CNAME` 레코드에만 표시합니다.
- Cloudflare API가 레코드 생성이나 업데이트를 거부할 때 표시하는 오류 메시지를 개선했습니다.
- Windows와 Linux 앱을 자동으로 생성하도록 CI/CD를 활성화했습니다.

## [1.1.1] - 2026-06-25
### 추가 / 수정됨
- 앱을 열면 인증 방식에 따라 비밀번호 또는 생체 인증 필드에 키보드 초점을 둡니다.
- 도메인 및 DNS 목록 검색을 여는 `Ctrl + F` 단축키를 추가했습니다.
- 검색을 닫는 `Esc` 단축키를 추가했습니다.
- DNS 레코드 생성 및 편집 화면을 닫는 `Esc` 단축키를 추가했습니다.
- DNS 편집 또는 설정 화면에서 도메인 목록으로 돌아가는 `Esc` 단축키를 추가했습니다.
- 로그인 화면의 비밀번호 필드에서 `Enter`를 누르면 로그인합니다.
- 레코드 생성 및 편집 중 하위 도메인 또는 내용 필드에서 `Enter`를 누르면 저장합니다.

## [1.1.0] - 2026-06-25
### 추가됨
- Windows 빌드 및 테스트 문서를 추가했습니다.
- Linux 빌드 및 테스트 문서를 추가했습니다.
### 보안
- Cloudflare API 토큰을 각 플랫폼의 보안 저장소를 사용하는 `flutter_secure_storage`에 저장합니다.
- 앱 비밀번호를 일반 텍스트 대신 임의 솔트가 포함된 PBKDF2-HMAC-SHA256 해시로 보안 저장소에 저장합니다.
- 인증 세션은 메모리에만 유지되며 앱을 다시 열면 로그인이 필요합니다.
- 테마와 DNS 유형 등 민감하지 않은 설정만 `shared_preferences`에 저장합니다.
