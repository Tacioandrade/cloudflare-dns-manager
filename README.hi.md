# Cloudflare DNS Manager

Cloudflare API के माध्यम से DNS रिकॉर्ड प्रबंधित करने वाला Flutter ऐप।

इस README में सभी प्लेटफ़ॉर्म की साझा जानकारी है। बिल्ड, परीक्षण और प्लेटफ़ॉर्म संबंधी विवरण के लिए [Android](README-Android.md), [Linux](README-Linux.md), [Windows](README-Windows.md), [iOS](README-iOS.md) और [macOS](README-macOS.md) मार्गदर्शिकाएँ देखें।

## विशेषताएँ

- स्थानीय पासवर्ड से लॉगिन और समर्थित प्लेटफ़ॉर्म पर बायोमेट्रिक लॉगिन।
- ऐप बंद करके दोबारा खोलने पर अपने आप लॉग आउट।
- सक्रिय, लंबित और निष्क्रिय स्थिति के साथ डोमेन सूची।
- कॉन्फ़िगर करने योग्य DNS रिकॉर्ड संपादक, Cloudflare प्रॉक्सी नियंत्रण और CDN कैश साफ़ करने की सुविधा।
- Cloudflare API टोकन कॉन्फ़िगर और सत्यापित करने की सुविधा।
- लाइट, डार्क या सिस्टम थीम; पुर्तगाली, अंग्रेज़ी, फ़्रेंच, स्पेनिश, सरलीकृत चीनी, जापानी, जर्मन, अरबी, हिन्दी और कोरियाई इंटरफ़ेस।
- ऐप के भीतर स्थानीयकृत संस्करण इतिहास।

## पहुँच और सुरक्षा

पहली बार ऐप खोलने पर पासवर्ड बनाएँ। हर नए सत्र में फिर से लॉगिन करना होता है। सत्र केवल मेमोरी में रहता है। पासवर्ड को यादृच्छिक सॉल्ट के साथ PBKDF2-HMAC-SHA256 हैश के रूप में प्लेटफ़ॉर्म के सुरक्षित स्टोरेज में रखा जाता है। Cloudflare टोकन भी सुरक्षित स्टोरेज में रहता है। थीम और DNS सेटिंग्स सामान्य स्थानीय प्राथमिकताओं में रखी जाती हैं।

## Cloudflare API टोकन

1. ऐप में साइन इन करें।
2. **सेटिंग्स** खोलें।
3. अपना [Cloudflare API टोकन](https://dash.cloudflare.com/profile/api-tokens) चिपकाएँ।
4. **टेस्ट** और फिर **सेव** चुनें।

### केवल पंजीकृत डोमेन प्रबंधित करने के लिए API टोकन

मौजूदा डोमेन की सूची, सक्रियण जाँच और CDN कैश साफ़ करने के लिए उपयोग करें:

- **Zone / Zone / Edit**: ज़ोन सूचीबद्ध करने और लंबित ज़ोन का सक्रियण फिर जाँचने के लिए।
- **Zone / Cache Purge / Purge**: CDN कैश साफ़ करने के लिए।

इस प्रोफ़ाइल से DNS रिकॉर्ड बनाए, बदले या हटाए नहीं जा सकते।

### नए डोमेन जोड़ने और मौजूदा डोमेन प्रबंधित करने के लिए API टोकन

ऊपर की अनुमतियों के साथ ये अनुमतियाँ जोड़ें:

- **Zone / DNS / Edit**: DNS रिकॉर्ड सूचीबद्ध करने, बनाने, बदलने और हटाने के लिए।
- **Zone resources / Include / All zones**.
- **User / Memberships / Read**: बिना डोमेन वाले खातों सहित सभी सुलभ खाते देखने के लिए अनुशंसित।

## संरचना

- Flutter / Dart; गैर-संवेदनशील स्थानीय डेटा के लिए `shared_preferences`।
- गोपनीय जानकारी के लिए `flutter_secure_storage`; बायोमेट्रिक प्रमाणीकरण के लिए `local_auth`।
- नेटवर्क के लिए `http` और बाहरी लिंक के लिए `url_launcher`।
