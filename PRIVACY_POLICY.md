## Português

# Política de Privacidade — Cloudflare DNS Manager

**Última atualização: 27 de julho de 2026**

O Cloudflare DNS Manager foi desenvolvido com foco em privacidade e segurança. Esta Política de Privacidade explica como as informações são tratadas durante o uso do aplicativo.

### 1. Coleta de dados

O Cloudflare DNS Manager não coleta, monitora, vende ou compartilha dados pessoais dos usuários.

O aplicativo não utiliza:

- Serviços de análise ou telemetria;
- Rastreamento de usuários;
- Identificadores para publicidade;
- Anúncios;
- Serviços próprios de armazenamento em nuvem;
- Servidores controlados pelo desenvolvedor para processar ou armazenar dados do usuário.

### 2. Armazenamento local

As configurações e credenciais cadastradas no aplicativo permanecem armazenadas localmente no dispositivo do usuário.

Isso pode incluir:

- Token da API da Cloudflare;
- Preferências de idioma e tema;
- Tipos de registros DNS selecionados;
- Preferência de verificação de atualizações;
- Senha local de acesso ao aplicativo.

O token da Cloudflare é armazenado utilizando o mecanismo de armazenamento seguro disponibilizado pelo sistema operacional.

A senha local não é armazenada em texto simples. O aplicativo mantém somente uma representação criptográfica da senha, protegida com hash, salt aleatório e múltiplas iterações.

O desenvolvedor não possui acesso a essas informações.

### 3. Comunicação com a Cloudflare

Para executar suas funcionalidades, o aplicativo se comunica diretamente com a API oficial da Cloudflare.

O token da API e os dados necessários para consultar ou modificar registros DNS são enviados exclusivamente à Cloudflare por meio de conexão HTTPS. Essas informações não passam por servidores controlados pelo desenvolvedor.

A Cloudflare poderá processar informações técnicas inerentes à conexão, como endereço IP e registros de acesso, de acordo com sua própria política de privacidade.

### 4. Verificação de atualizações

Nas plataformas compatíveis, o aplicativo poderá consultar diretamente a API pública do GitHub para verificar se existe uma nova versão disponível.

Essa consulta não envia o token da Cloudflare, a senha local, os registros DNS ou outras configurações armazenadas no aplicativo. Entretanto, o GitHub poderá receber informações técnicas inerentes à conexão, como endereço IP e cabeçalhos HTTP.

A verificação automática de atualizações pode ser desativada nas configurações do aplicativo.

### 5. Compartilhamento de dados

O desenvolvedor não recebe, armazena, compartilha ou comercializa dados pessoais, credenciais ou informações de DNS dos usuários.

As únicas comunicações externas realizadas pelo aplicativo são aquelas necessárias para:

- Acessar diretamente a API da Cloudflare;
- Consultar atualizações no GitHub, quando essa funcionalidade estiver disponível e habilitada;
- Abrir links externos escolhidos pelo usuário.

### 6. Permissões

O aplicativo solicita somente as permissões necessárias ao funcionamento dos recursos oferecidos, como acesso à internet e, quando disponível, autenticação biométrica.

Os dados biométricos são processados exclusivamente pelo sistema operacional. O aplicativo não recebe nem armazena impressões digitais, dados faciais ou outros dados biométricos.

### 7. Exclusão dos dados

Como os dados são mantidos localmente, o usuário pode removê-los ao:

- Apagar as credenciais nas configurações do aplicativo;
- Limpar os dados do aplicativo nas configurações do sistema operacional;
- Desinstalar o aplicativo.

Determinados dados também poderão estar sujeitos aos mecanismos de backup do próprio sistema operacional, conforme as configurações escolhidas pelo usuário.

### 8. Segurança

São utilizados recursos de armazenamento seguro fornecidos pelo sistema operacional e conexões HTTPS para proteger as informações.

Apesar dessas medidas, nenhum sistema eletrônico é completamente imune a riscos. O usuário é responsável por proteger o dispositivo, utilizar uma senha segura e conceder ao token da Cloudflare somente as permissões necessárias.

### 9. Privacidade de crianças

O Cloudflare DNS Manager não é direcionado especificamente a crianças e não coleta intencionalmente dados pessoais de crianças ou de outros usuários.

### 10. Alterações desta política

Esta Política de Privacidade poderá ser atualizada para refletir mudanças no aplicativo, requisitos legais ou melhorias de segurança. A versão mais recente será disponibilizada junto aos canais oficiais do projeto.

### 11. Contato

Dúvidas ou solicitações relacionadas à privacidade podem ser registradas no repositório oficial:

https://github.com/Tacioandrade/cloudflare-update-dns/

## English

# Privacy Policy — Cloudflare DNS Manager

**Last updated: July 27, 2026**

Cloudflare DNS Manager was developed with privacy and security in mind. This Privacy Policy explains how information is handled while you use the application.

### 1. Data collection

Cloudflare DNS Manager does not collect, monitor, sell, or share users' personal data.

The application does not use:

- Analytics or telemetry services;
- User tracking;
- Advertising identifiers;
- Advertisements;
- Developer-operated cloud storage services;
- Developer-controlled servers to process or store user data.

### 2. Local storage

Settings and credentials entered in the application remain stored locally on the user's device.

This may include:

- Cloudflare API token;
- Language and theme preferences;
- Selected DNS record types;
- Update-check preference;
- Local password used to access the application.

The Cloudflare token is stored using the secure storage mechanism provided by the operating system.

The local password is not stored as plain text. The application stores only a cryptographic representation of the password, protected with hashing, a random salt, and multiple iterations.

The developer does not have access to this information.

### 3. Communication with Cloudflare

To provide its features, the application communicates directly with the official Cloudflare API.

The API token and the data required to view or modify DNS records are sent exclusively to Cloudflare over an HTTPS connection. This information does not pass through servers controlled by the developer.

Cloudflare may process technical information inherent to the connection, such as the IP address and access logs, in accordance with its own privacy policy.

### 4. Update checks

On supported platforms, the application may directly query GitHub's public API to check whether a new version is available.

This request does not send the Cloudflare token, local password, DNS records, or other settings stored in the application. However, GitHub may receive technical information inherent to the connection, such as the IP address and HTTP headers.

Automatic update checks can be disabled in the application settings.

### 5. Data sharing

The developer does not receive, store, share, or sell users' personal data, credentials, or DNS information.

The application makes external connections only when necessary to:

- Access the Cloudflare API directly;
- Check for updates on GitHub when this feature is available and enabled;
- Open external links selected by the user.

### 6. Permissions

The application requests only the permissions required for its features, such as internet access and biometric authentication when available.

Biometric data is processed exclusively by the operating system. The application does not receive or store fingerprints, facial data, or any other biometric data.

### 7. Data deletion

Because data is stored locally, users can remove it by:

- Deleting credentials in the application settings;
- Clearing the application's data in the operating system settings;
- Uninstalling the application.

Some data may also be included in operating-system backup mechanisms, depending on the settings selected by the user.

### 8. Security

Secure storage features provided by the operating system and HTTPS connections are used to protect information.

Despite these measures, no electronic system is completely immune to risk. Users are responsible for protecting their devices, using a strong password, and granting the Cloudflare token only the permissions necessary for its intended use.

### 9. Children's privacy

Cloudflare DNS Manager is not specifically directed at children and does not intentionally collect personal data from children or other users.

### 10. Changes to this policy

This Privacy Policy may be updated to reflect changes to the application, legal requirements, or security improvements. The latest version will be made available through the project's official channels.

### 11. Contact

Questions or requests related to privacy may be submitted through the official repository:

https://github.com/Tacioandrade/cloudflare-update-dns/

Cloudflare DNS Manager 不收集、监控、出售或共享用户的个人数据。

- 分析或遥测服务；
- 用户跟踪技术；
- 广告标识符；

- 由开发者控制、用于处理或存储用户数据的服务器。

在应用程序中输入的设置和凭据仅保存在用户自己的设备上。

这些信息可能包括：

- Cloudflare API 令牌；
- 语言和主题偏好；
- 所选的 DNS 记录类型；
- 更新检查偏好；
- 用于访问应用程序的本地密码。

本地密码不会以明文形式保存。应用程序仅保存密码的加密表示，并通过哈希、随机盐值和多次迭代进行保护。

### 5. 数据共享

开发者不接收、不存储、不共享也不出售用户的个人数据、凭据或 DNS 信息。

本应用程序仅在以下必要情况下建立外部连接：

- 直接访问 Cloudflare API；
- 在该功能可用且已启用时，通过 GitHub 检查更新；
- 打开用户选择的外部链接。

### 6. 权限

本应用程序仅请求其功能所必需的权限，例如互联网访问权限，以及在可用时使用生物识别身份验证的权限。

生物识别数据完全由操作系统处理。本应用程序不会接收或存储指纹、面部数据或任何其他生物识别数据。

### 7. 数据删除

由于数据保存在本地，用户可以通过以下方式将其删除：

- 在应用程序设置中删除凭据；
- 在操作系统设置中清除应用程序数据；
- 卸载应用程序。

根据用户选择的设置，某些数据也可能包含在操作系统的备份机制中。

本应用程序使用操作系统提供的安全存储功能和 HTTPS 连接来保护信息。

### 10. 本政策的变更

Cloudflare DNS Manager は、ユーザーの個人データを収集、監視、販売、または共有しません。

### 2. ローカルストレージ

アプリケーションに入力された設定と認証情報は、ユーザーの端末内にのみ保存されます。

これには以下の情報が含まれる場合があります。

- Cloudflare API トークン
- 言語とテーマの設定
- 選択された DNS レコードの種類
- 更新確認の設定
- アプリケーションへのアクセスに使用するローカルパスワード

Cloudflare トークンは、オペレーティングシステムが提供する安全なストレージ機構を使用して保存されます。

ローカルパスワードは平文では保存されません。アプリケーションは、ハッシュ、ランダムなソルト、および複数回の反復処理によって保護された、パスワードの暗号学的表現のみを保存します。

開発者はこれらの情報にアクセスできません。

### 3. Cloudflare との通信

機能を提供するため、本アプリケーションは Cloudflare の公式 API と直接通信します。

API トークンおよび DNS レコードの参照または変更に必要なデータは、HTTPS 接続を通じて Cloudflare のみに送信されます。これらの情報が開発者の管理するサーバーを経由することはありません。

Cloudflare は、独自のプライバシーポリシーに従い、IP アドレスやアクセスログなど、接続に伴う技術情報を処理する場合があります。

対応しているプラットフォームでは、新しいバージョンが利用可能かを確認するため、本アプリケーションが GitHub の公開 API に直接問い合わせる場合があります。

このリクエストによって、Cloudflare トークン、ローカルパスワード、DNS レコード、またはアプリケーション内に保存されたその他の設定が送信されることはありません。ただし、GitHub は IP アドレスや HTTP ヘッダーなど、接続に伴う技術情報を受け取る場合があります。

更新の自動確認は、アプリケーションの設定で無効にできます。

### 5. データの共有

開発者がユーザーの個人データ、認証情報、または DNS 情報を受信、保存、共有、もしくは販売することはありません。

本アプリケーションが外部通信を行うのは、以下の目的で必要な場合に限られます。

- Cloudflare API に直接アクセスするため
- この機能が利用可能かつ有効な場合に、GitHub で更新を確認するため
- ユーザーが選択した外部リンクを開くため

### 6. 権限

本アプリケーションは、インターネットへのアクセスや、利用可能な場合の生体認証など、提供する機能に必要な権限のみを要求します。

生体情報はオペレーティングシステムによってのみ処理されます。本アプリケーションが指紋、顔情報、またはその他の生体情報を受信または保存することはありません。

### 7. データの削除

データは端末内に保存されるため、ユーザーは以下の方法で削除できます。

- アプリケーションの設定から認証情報を削除する
- オペレーティングシステムの設定からアプリケーションのデータを消去する
- アプリケーションをアンインストールする

ユーザーが選択した設定によっては、一部のデータがオペレーティングシステムのバックアップ機能に含まれる場合があります。

### 8. セキュリティ

情報を保護するため、オペレーティングシステムが提供する安全なストレージ機能と HTTPS 接続を使用します。

これらの対策を講じていても、電子システムからリスクを完全に排除することはできません。ユーザーは、自身の端末を保護し、安全性の高いパスワードを使用し、Cloudflare トークンには意図した用途に必要な権限のみを付与する責任があります。

### 9. 子どものプライバシー

Cloudflare DNS Manager は特に子どもを対象としたものではなく、子どもまたはその他のユーザーの個人データを意図的に収集することはありません。
